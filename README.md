# Machine Learning Projects

A collection of three machine learning projects built to practice data
preprocessing, model development, and evaluating results.

## 1. Spam vs. Ham Message Classification (`spam_ham`)

A text-classification project that identifies whether a message is
**spam** or **ham** (legitimate). It demonstrates how machine learning
can be used to classify text messages.

## 2. Student Performance Prediction (`student_performance`)

A regression project that uses student-related data to predict academic
performance. The project explores preparing a dataset, training a
regression model, and evaluating prediction performance.

## 3. E-commerce Customer Satisfaction (`E_commerce_customer_satisfaction`)

A machine learning project focused on e-commerce customer satisfaction.
It explores customer-related data to identify patterns that can help
understand or predict customer satisfaction.
